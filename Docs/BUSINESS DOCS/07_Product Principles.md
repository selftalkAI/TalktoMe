# Product Principles

*Version 0.3 | Company Document 07*

Define rules that product decisions must follow.

## Principles

- **One coherent Profile, not fragments (integrate)** — Brain 2 synthesizes memories and beliefs across the complete human persona into a single standing account per domain, not disconnected logs the user has to piece together themselves.
- **Evidence before interpretation** — Important reflections link back to source memories.
- **Never overwrite history** — A new belief, or a new Profile entry, creates a new version; it does not erase the old one.
- **Fact is not inference** — Observed, derived, inferred, confirmed and rejected information remain distinct.
- **User remains the authority** — The user can correct the system.
- **Propose, never write (agency with boundaries)** — Brain 2 may analyze, prepare insights, and draft a refinement to the user's memory, beliefs, or Profile — but only the user's explicit acceptance makes it durable or supersedes a prior version. Automatic or inferred acceptance is never permitted, for any consequential action or any Profile write, whether triggered by the user or by a recurring automatic check.
- **Progressive intelligence** — Start useful with simple memory/RAG; add proprietary ML where data and value justify it.
- **Privacy is product** — Export, deletion, access and consent are core features, and the Profile is visible only to its owning user by default.

## Working Status

This is a working document. It should evolve through founder usage, user research, product experiments, technical validation, and legal/security review.
