# User Journey and Use Cases

*Version 0.3 | Company Document 09*

Describe how a person experiences selfie.Me end to end.

## Journey 1 — Memory and Evolution

1. **Capture:** speak/write naturally.
2. **Processing:** Brain 2 extracts memories, beliefs, goals, decisions and context.
3. **Linking:** related historical items are connected.
4. **Evolution:** changes are detected and scored.
5. **Reflection:** Brain 2 prepares evidence-backed insight.
6. **Confirmation:** user accepts, edits or rejects the interpretation.
7. **Future use:** advisor reasoning retrieves relevant history before new decisions.

## Journey 2 — Profile Refinement

1. User shares input about a tracked domain, anywhere across their complete human persona (a skill, an emotion, a relationship, a habit, a learning area) — text, audio, video, or photo.
2. Brain 2 checks whether the input carries the user's own reflection; if not, it asks a clarifying question first.
3. Brain 2 retrieves the current Profile entry for that domain and compares the input against outside expert knowledge.
4. Brain 2 proposes a refinement and explains why.
5. The user accepts, asks for further refinement, or rejects it.
6. On acceptance, the new version supersedes the old one; the prior version stays visible in history.
7. Brain 2 follows through — a nudge, a reminder, a check-in — so the accepted change actually takes hold in the user's life, not just in the Profile's data.
8. On a regular cadence, Brain 2 may repeat steps 3–5 on its own for an existing entry, unless the user has turned that off for that domain.

## Primary Use Cases

- How has my thinking about X changed?
- Why did I change my mind?
- What did I expect when I made this decision?
- What happened afterward?
- What patterns repeat in similar situations?
- What should I consider now based on my own history?
- How does my current approach to a skill/habit compare to the best known way of doing it, and should I change anything?
