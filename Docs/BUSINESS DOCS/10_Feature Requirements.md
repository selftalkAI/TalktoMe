# Feature Requirements

*Version 0.3 | Company Document 10*

Define the initial feature set in product terms.

## Capture

Voice recording, transcription, text journal, timestamps, source playback.

## Memory

Summary, topics, people, events, goals, decisions, beliefs, source links.

## Evolution

Related-belief matching, version timeline, change type, confidence, possible causes, user confirmation.

## Reflection

Weekly/monthly changes, unresolved decisions, recurring themes, evidence links.

## Advisor

Retrieve similar past decisions, outcomes and lessons before giving suggestions.

## Profile

Per-domain versioned entries spanning the complete human persona (skill, emotion, relationships, career, learning, habits, extensible — not a fixed list); refinement proposals sourced from the user's own reflection plus an outside-knowledge lookup; explicit accept/refine/reject controls; full version history; follow-through support (nudges, reminders, check-ins) once a refinement is accepted; a per-domain toggle for automatic periodic re-evaluation.

## Control

Edit/correct, export, delete, permissions, agent activity visibility.

## Working Status

This is a working document. It should evolve through founder usage, user research, product experiments, technical validation, and legal/security review.

## Basis

Grounded in the selfie.Me Strategic Framework and Business Model Canvas, the founder's clarified direction, and the Brain 1 / Brain 2 design in `Docs/FEATURES/Building_Brain1.md` and `Building_Brain2.md`, formalized in the Architecture, Functional and Technical Design Documents (V03).
