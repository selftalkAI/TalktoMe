# Decision Intelligence Model

*Version 0.3 | Company Document 15*

Define decision -> outcome -> lesson intelligence.

## Decision Record

Decision, date, alternatives, reasons, constraints, expected outcome, confidence, people involved, linked beliefs/goals.

## Outcome Record

Actual result, date, success indicators, unexpected consequences, user evaluation.

## Learning Record

Compare expected vs actual outcome and capture a user-confirmed lesson.

## Advisor Behavior

For a new decision, retrieve semantically and structurally similar past decisions, show outcomes, and present considerations rather than commands. The same rule governs every Profile proposal: Brain 2 suggests, the user decides.

## Working Status

This is a working document. It should evolve through founder usage, user research, product experiments, technical validation, and legal/security review.

## Basis

Grounded in the selfie.Me Strategic Framework and Business Model Canvas, the founder's clarified direction, and the Two Brains / Profile implementation plan formalized in the Architecture, Functional and Technical Design Documents (V02).
