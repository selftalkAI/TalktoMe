# Metrics and KPI Framework

*Version 0.3 | Company Document 35*

Define what success means.

## Activation

- First capture completed.
- First memory retrieved.
- First evolution timeline created.

## Engagement

- Capture days/week.
- Weekly reflection opens.
- Search/advisor usage.
- Corrections/confirmations.

## Value

- Percentage of reflections marked useful.
- Percentage of evolution inferences confirmed.
- Number of past decisions successfully rediscovered.
- Profile proposals accepted per active user.
- Percentage of accepted proposals where the user later confirms real follow-through (not just an accepted, unused update).

## Trust

- Unsupported-claim rate.
- Deletion success.
- Privacy/security incidents.
- User correction rate by inference type.
- Unaccepted Profile writes (target: zero — release-blocking if ever nonzero, since the accept-gate is a trust guardrail, not just a feature detail).

## Retention

30/60/90-day retained users and continued capture behavior.

## North Star

Meaningful, evidence-backed personal insights delivered per active user over time.

## Working Status

This is a working document. It should evolve through founder usage, user research, product experiments, technical validation, and legal/security review.

## Basis

Grounded in the selfie.Me Strategic Framework and Business Model Canvas, the founder's clarified direction, and the Two Brains / Profile implementation plan formalized in the Architecture, Functional and Technical Design Documents (V02).
