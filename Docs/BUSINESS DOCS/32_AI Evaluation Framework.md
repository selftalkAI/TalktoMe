# AI Evaluation Framework

*Version 0.3 | Company Document 32*

Define measurable quality for agentic personal intelligence.

## Core Metrics

- Memory extraction precision.
- Retrieval Recall@K / ranking quality.
- Belief-change precision and false-positive rate.
- Evidence coverage.
- Inference acceptance/rejection rate.
- Correction recurrence rate.
- Hallucination/unsupported-claim rate.
- Agent task completion and unnecessary-action rate.
- Profile proposal acceptance rate.
- Outside-knowledge grounding accuracy (is the cited benchmark correct and attributed).
- Follow-through effectiveness — of accepted refinements, what fraction lead to a real, user-confirmed change, not just a stored update.

## Human Evaluation

Ask whether an insight is accurate, supported, useful, non-obvious, appropriately uncertain and respectful of user agency.

## North-Star Evaluation

Can the system reconstruct an important evolution in the user's thinking with correct evidence and a useful explanation? And — the internal bar for the still-undecided Legacy feature, evaluated long before it is ever built for anyone else — can the Profile answer a situational question about the user accurately enough that the user themselves would recognize it as fair?
